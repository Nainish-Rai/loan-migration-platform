# @lmp/contracts

Wire formats shared between services, for TypeScript:
- `src/gen/`: protobuf-es output from `contracts/proto` and Envoy's ext_authz protos. Generated by `buf generate` on every build and gitignored.
- `src/events/`: types for the events described in `contracts/events`.
- `src/activities/`: one interface per Temporal task queue, so the runs workflow calls every service with typed activities.

Only adapters import this package. The domain and application rings never see a wire type.
